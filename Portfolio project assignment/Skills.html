Skills

Throughout my limited programming experience, I have gained a few soft and hard skills. I believe these skills are gained as a byproduct of the profession. Some of these where obtained faster than others Some took years to develop. As a Software developer you are constantly learning new things all the time. You must adapt to new technologys as they come and in doing so, you will develop the skills and confidence you need to carry out your work. Below I will speak about a few of the skills I have gained as I developed these projects.

Communication

Having good communication skills in general carries you far. Software developement is no different. This was especially true when developing both GuitarZero and Snake of knowledge. I had to speak with my team constantly, Updating them on design choices, design decisions and aloocating tasks to my team members

Problem solving

I have demonstrated problem solving skills throughout my various projects. For example, when developing my todolist app I had to figure out how to save user input into a file. Everytime I tried to do this However it would return the object itself, not the text I want to display. To solve this issue I appended the user input into a list, and then write the items inside the list into a file. This way the input (string) would save as a string of text and not an object

HTML CSS AND JAVASCRIPT

I have demonstrated these skills through my website projects such as GuitarZero.com and SOK.com (SnakeOfKnowledge). Through building these websites with a team

Python

Using python I have demonstrated skills such as file handeling, user input handeling and GUI interfaces through my todolist app.

I learned about functions, signals and OOP through building my platformer game. I also learned collision detection, animation, tweening, and tilemap through building the various levels.
