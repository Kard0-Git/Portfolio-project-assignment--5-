Paint app

An individual project for my introduction to programming module. We had to create an interactive application using the p5.js javascript framework. In this project, I created a paint app, similar to ms paint on your computer. You can draw anything you like and save it on your computer.

Features

  • Local storage
  • Darkmode/lightmode toggle
  • Text colour changer
  • Colour Picker
  • Canvas Resizer(Based on numerical input)
  • Image loader
  • Save function
  • Brush size toggle
  • Brush head selector
  • Eraser
  • Drawing functionality
  • Clear canvas button to clear everything drawn on the canvas

Todolist app

In this project I made my own todolist application with python, using the tkinter module. This is a personal project I created to learn more about the tkinter module and its various features. The todolist allows the user to save their notes in a text document in the todolist directory. They can then open the text document and see their notes

Features

  • Text input feild
  • Colour picker for both the frame fill and the background
  • Basic file handling
  • Button to clear notes, clear last note, etc
  • Button to reset background
  • Button to clear text input
You can find this project on my github page
